# 3. 核心玩法约束

请在后端设计里明确以下约束：

1. 玩家只有一个角色。
2. 玩家同一时间只能处于以下状态之一：

   * `free`
   * `battle`
   * `garrisoning`
3. Garrison 不是底部 Tab，是 pushed route。
4. PVP 是异步自动结算，不做实时战斗。
5. PVE / PVP 战斗都由后端自动结算。
6. 驻守收益使用懒结算：

   * 不需要每分钟定时写入收益。
   * 打开 Home / Garrison / Claim 时根据时间计算累计收益。
   * 超过 reward cap 后停止继续累计。
7. 被击败只失去当前据点。
8. 被击败时自动结算或保留可领取收益，具体请根据当前前端 Garrison node lost 状态设计合理 contract。
9. 玩家已解锁楼层不应因为被击败而回退。
10. 占领某据点后，玩家不能继续挑战其他据点，除非先 Leave。
11. Battle Result 应能驱动：

    * Return to Floor
    * Occupy
    * Equip dropped gear if applicable
12. Equipment 应能驱动：

    * view equipped gear
    * view backpack
    * compare gear
    * equip gear
    * auto-equip best gear
13. Reports 应能显示：

    * attack win
    * attack loss
    * defense win
    * node lost
    * unread state
    * rewards if any
    * battle result / replay link if applicable
